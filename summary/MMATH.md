# MMATH: A Multilingual Benchmark for Mathematical Reasoning

**论文信息**：
- 作者：Wenyang Luo, Wayne Xin Zhao, Jing Sha, Shijin Wang, Ji-Rong Wen
- 发表/来源：arXiv:2505.19126
- 时间：2025年5月25日
- 链接：https://arxiv.org/abs/2505.19126
- 代码：https://github.com/RUCAIBox/MMATH

## 研究背景与动机

大型推理模型（OpenAI o1、DeepSeek R1）推进了复杂推理，但多语言复杂推理能力仍未被充分探索。现有工作主要聚焦简单任务如 MGSM，更复杂的基准（如 AIME）几乎全是单语。此外，模型在回答非英语问题时存在**off-target 问题**——用非目标语言生成回答。

## 核心方法/贡献

1. **MMATH 基准**：374道高质量数学题，覆盖10种类型学多样语言
   - 题目来源：AIME 2024（30题）、CNMO（15题）、MATH-500
   - 翻译+验证流水线：前沿LLM翻译 + 人工验证确保语义一致

2. **Off-target 问题量化**：引入语言一致性比率（LCR）指标
   - LCR 衡量输入与输出之间的语言对齐程度
   - 即使 DeepSeek R1 也存在显著的语言间性能差异和 off-target 问题

3. **策略探索**：
   - Prompt 策略：引导模型在英语中推理、在目标语言中回答
   - 训练策略：通过监督学习对齐多语言输入与英语推理能力
   - 发现：英语推理+目标语言回答可同时提升性能和保持语言一致性

## 实验与结果

- 10种语言上的广泛评估
- 低资源语言中，用英语推理一致性地提升性能
- Off-target 现象在非拉丁文字语言中更为严重
- Prompt策略（英语思考+目标语言回答）在多数模型上有效

## 数据集详情

- **规模**：374道数学题 × 10种语言
- **语言覆盖**：10种类型学和地理多样性语言
- **构建方法**：从 AIME、CNMO、MATH-500 精选 → LLM翻译 → 人工验证
- **许可协议**：开源（代码和数据在 GitHub 公开）
- **数据质量**：前沿LLM翻译 + 人工验证确保语义一致性

## 局限性

- 374道题规模有限（但质量高）
- 翻译可能引入语义偏差
- Off-target 问题的根本原因仍需更深入研究

## 对多语言数据集领域的意义

MMATH 是首个面向复杂数学推理的多语言基准（比 MGSM 难得多），揭示了高级推理模型在多语言场景下的关键弱点：off-target 问题和语言间性能差异。提出的 LCR 指标和英语推理策略为多语言推理研究提供了重要工具和方向。

## 关键要点

- 374道高质量数学题，10种语言，来自AIME/CNMO/MATH-500
- 发现 off-target 问题：模型用非目标语言回答（非拉丁文字更严重）
- 引入 LCR（语言一致性比率）指标量化 off-target 问题
- 英语推理+目标语言回答的策略同时提升性能和语言一致性
- 即使 DeepSeek R1 也存在显著语言间性能差异
