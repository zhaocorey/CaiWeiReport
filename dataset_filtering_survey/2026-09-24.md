**1. AutoData: Agentic Search for Pre-training Data Selection**
- 链接: https://arxiv.org/abs/2609.19754
- 摘要: Frames pre-training data selection as heuristic engineering over per-document features. Introduces AutoData, an agent that searches over executable selection algorithms, discovering feature interactions automatically via proxy model validation feedback.
- 实用价值: ⭐⭐⭐

**2. Quality over Quantity: Diversity-Aware Data Selection for Efficient Verilog Code Generation**
- 链接: https://arxiv.org/abs/2609.22765
- 摘要: Proposes VeriSelector, the first data selection framework for Verilog code generation that jointly optimizes quality and diversity via constrained bi-objective subset selection with IFD scoring and structural feature clustering.
- 实用价值: ⭐⭐

**3. GRACE: Gradient-guided Coreset Selection for LLM Unlearning**
- 链接: https://arxiv.org/abs/2608.28361
- 摘要: Gradient-guided coreset selection for constructing forget and retain sets in LLM unlearning. Uses non-negative orthogonal matching pursuit for forget set and clustered orthogonal matching pursuit for retain set. Accepted at EMNLP Findings.
- 实用价值: ⭐⭐

**4. Hierarchical Data Selection via Manifold Coverage and Sparse Feature Coverage in LLM Post-training (MASS)**
- 链接: https://arxiv.org/abs/2608.16927
- 摘要: Formulates SFT data selection as coarse-to-fine hierarchical coverage. Uses dense autoencoder for manifold-based semantic grouping and TopK sparse autoencoder for quality-aware feature coverage within groups.
- 实用价值: ⭐⭐

**5. Data-DPO: Direct Preference Optimization for Target Model Data Selection in LLM Post-Training**
- 链接: https://arxiv.org/abs/2608.16926
- 摘要: Target model-oriented SFT data selection using one-step probing to convert activation differences into pairwise preferences. Trains lightweight reward model for target-model-aware data selection combined with quality scores and diversity.
- 实用价值: ⭐⭐

**6. SieveIVF: Threshold-Aware IVF Execution for Large-Scale Training Data Deduplication**
- 链接: https://arxiv.org/abs/2608.03199
- 摘要: Threshold-aware IVF executor for embedding-based deduplication that stops early when no qualifying candidates remain. Achieves 4.1-8.4x speedup over fixed-probe IVF on Hunyuan workloads with minimal recall loss.
- 实用价值: ⭐⭐

**7. PPL-Factory: Task-Aware and Budget-Aware Data Selection from Language Modeling to Reasoning**
- 链接: https://arxiv.org/abs/2607.18199
- 摘要: Task-aware and budget-aware data selection framework for LLM fine-tuning that selects informative training samples to reduce computational cost while preserving downstream performance.
- 实用价值: ⭐⭐

**8. Neuron-Aware Data Selection for Annotation-Free LLM Self-Distillation (Neuron-OPSD)**
- 链接: https://arxiv.org/abs/2607.02460
- 摘要: Uses internal neuron activations to guide training-data selection and teacher context construction for annotation-free self-distillation. Improves in-domain performance while preserving cross-domain generalization.
- 实用价值: ⭐⭐

**9. Online Data Selection for Instruction Tuning via Gaussian Processes (GAIA)**
- 链接: https://arxiv.org/abs/2606.30077
- 摘要: Formulates data valuation as global estimation using Gaussian Process regression to model continuous utility manifolds. Adaptive strategy fusion with dynamic-regret guarantees for non-stationary quality scores during training.
- 实用价值: ⭐⭐⭐

**10. DRIFT: Refining Instruction Data via On-Policy Data Attribution**
- 链接: https://arxiv.org/abs/2606.18307
- 摘要: On-policy data attribution method for refining instruction tuning data. Uses gradient-based attribution to identify and refine influential training examples.
- 实用价值: ⭐⭐

**11. RegMix-D: Dynamic Data Mixing via Proxy Training Trajectories**
- 链接: https://arxiv.org/abs/2606.18663
- 摘要: Extends RegMix to dynamic mixing by training regression models on full loss trajectories from proxy runs. Supports offline and online variants, surpassing RegMix with only 25% of proxy compute budget.

**12. Coresets Before Score Sets: Evaluation-Unsupervised Prompt Subset Selection for LLM Benchmarks**
- 链接: https://arxiv.org/abs/2607.09739
- 摘要: Unsupervised coreset selection for LLM benchmark evaluation. Selects representative prompt subsets without requiring score labels, enabling efficient evaluation.

**13. CoT-Core: Accelerating LLM Evaluation via CoT-Aware Coreset Selection**
- 链接: https://arxiv.org/abs/2608.00014

**14. Influcoder: Distilling Decoders' Gradient Influence Rankings into an Encoder for Data Attribution**
- 链接: https://arxiv.org/abs/2606.13668

## 📊 趋势洞察

### 关键趋势

1. **智能体化数据选择**: AutoData 将预训练数据选择重构为 agent 搜索问题，标志着从规则/启发式 → agent-based 的范式转移
2. **极端数据效率**: LIMIT 仅用 ~800 样本超越 20x 数据量，印证"少而精"趋势
3. **DPO 思路用于数据选择**: Data-DPO 直接借用偏好优化框架做目标模型感知选择，方法论跨界
4. **去重工程化**: SieveIVF 将去重从学术方法推向工程级执行（4-8x 加速）
5. **合成数据治理**: SynthSentry 解决合成数据污染检测，反映训练数据中合成内容占比上升的现实

### 对多语言数据集构建的启示

- **AutoData/LIMIT** 可直接用于多语言预训练数据的自动筛选
- **MASS** 的流形覆盖方法适合多语言空间中的数据分布建模
- **DomainPilot** 域级混合优化对多语言数据配比特别有价值
- **SieveIVF** 对大规模多语言语料的去重效率提升显著
